Dragons of Mugloar · one turn at a time

Mugloar game loop

How one game runs against the API, from start to game over: first what the API itself does, then how the bot and the browser client each drive it.

What a turn is

A game is a sequence of turns, and only three calls take one. Everything else is a free read.

CallTakes a turnReturns
POST /game/startnogameId, 3 lives, 0 gold, level 0, score 0, turn 0
GET /:gameId/messagesnothe board: about ten ads, each with a reward, a label and expiresIn turns
GET /:gameId/shopnothe items for sale; the same for the whole game
POST /:gameId/solve/:adIdyessuccess, lives, gold, score, turn, a flavour message
POST /:gameId/shop/buy/:itemIdyes, even when it failssuccess, gold, lives, level, turn
POST /:gameId/investigate/reputationyespeople, state, underworld; no stats
  • Stats only come back from turns. There is no call that reads lives, gold or score for free, so a client keeps its own copy and merges each response into it.
  • Ads expire by turns, not by time. A board read stays valid until the next turn.
  • Game over is a response with 0 lives. After that, reading the board returns 404.
  • Idle games expire somewhere between 5 and about 40 minutes after the last action; the exact timeout is unknown. Reading the board of an expired game returns 404.

One game on the wire

sequenceDiagram
  participant C as Client (bot or browser)
  participant M as Mugloar API
  C->>M: POST /game/start
  M-->>C: gameId, starting stats
  C->>M: GET /:gameId/shop
  M-->>C: items (read once)
  loop until lives = 0
    C->>M: GET /:gameId/messages
    M-->>C: board
    Note over C: pick a job or an item
    alt solve
      C->>M: POST /:gameId/solve/:adId
      M-->>C: success, lives, gold, score, turn
    else buy
      C->>M: POST /:gameId/shop/buy/:itemId
      M-->>C: success, gold, lives, level, turn
    end
    Note over C: merge stats, log the turn
  end
  Note over C: lives = 0: game over

In the bot

GamePlayer.play() runs this loop on its own. The decision tree picks every move; Enter pauses between turns.

flowchart TD
  s(["Start"]) --> start["POST /game/start"]
  start --> shop["GET /shop<br/>once per game"]
  shop --> alive{"Lives left?"}
  alive -- no --> over["Summary: game over"]
  alive -- yes --> paused{"Paused?"}
  paused -- "yes: wait for Enter" --> paused
  paused -- no --> fetch["GET /messages<br/>decode, drop known-gone ads"]
  fetch -- "404" --> exp["Summary: game expired"]
  fetch -- ok --> decide["Strategy.decide()"]
  decide -- "nothing playable" --> stop["Summary: no playable move"]
  decide -- Solve --> solve["POST /solve/:adId"]
  decide -- Buy --> buy["POST /shop/buy/:itemId"]
  solve -- "404: ad gone" --> refetch["Forget it, read the board<br/>once more, decide again"]
  buy -- "404: item gone" --> refetch
  refetch -- "something to play" --> decide
  refetch -- "404 or nothing to play" --> stop2["Summary: board unavailable"]
  solve -- ok --> update["Merge stats,<br/>update the state estimate"]
  buy -- ok --> update
  update --> log["Report the turn:<br/>console and history file"]
  log --> alive

In the browser

The browser client runs the same loop, but the player makes every move. Each click goes through one pipeline in the game store.

flowchart TD
  s(["Start a new game"]) --> start["POST /game/start"]
  start --> load["GET /shop, then GET /messages"]
  open(["Open a game link"]) --> load
  load --> wait["Show board and shop,<br/>with hints; wait for the player"]
  wait -- "solve, buy or ask around" --> guard["Disable every control<br/>snapshot the stats"]
  guard --> act["POST solve, buy<br/>or reputation"]
  act -- ok --> merge["Merge stats, add a log entry,<br/>update the state estimate"]
  act -- "error, including a 404" --> err["Show the error"]
  merge --> dead{"Lives 0?"}
  dead -- yes --> over["Game over screen"]
  dead -- no --> board["GET /messages"]
  err --> board
  board -- ok --> wait
  board -- "404" --> expired["Back to start:<br/>game expired notice"]
  board -- "network, 5xx, 429" --> retry["Retry after 2 s, then 5 s"]
  retry -- ok --> wait
  retry -- "still failing" --> stale["Solving blocked;<br/>Check the board again button"]
  stale --> board

Opening a game link in a fresh tab loads the board and shop, but the stats show as unknown until the next turn returns them. The API has no free way to read them.
